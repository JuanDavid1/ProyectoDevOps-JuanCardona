# ProyectoDevOps-JuanCardona

## Descripción
Este proyecto fue creado como parte de la asignatura Modelos de Simulación
en la Corporación Universitaria Remington, sede Aquazul, Casanare.

## Objetivo
Implementar una cultura DevOps utilizando GitHub Actions, incluyendo
gestión de repositorios y pipelines de CI/CD.

## Tecnologías utilizadas
- GitHub Actions
- Git
- Node.js
- YAML Pipelines
